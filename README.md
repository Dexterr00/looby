# لوبي — موقع أفلام ومسلسلات وأنمي

قالب موقع جاهز (HTML + CSS + JS خالص، بدون أي إعداد بناء أو npm) يشبه في تجربته
سينيمانا/نتفلكس: هيرو متحرك، صفوف تصفح أفقية، بحث فوري، وبطاقة تفاصيل بشكل "تذكرة سينما"
مع تشغيل الإعلانات (Trailers) من يوتيوب.


الموقع **لا يستضيف ولا يبث أي فيلم أو حلقة كاملة** محمية بحقوق الملكية. إذا أردت إضافة
تشغيل فعلي للمحتوى، يجب ربطه بمزوّد محتوى تملك ترخيصًا قانونيًا لبثه (مثل اتفاقية توزيع،
أو مكتبة محتوى خاصة بك).

## خطوات التشغيل

### 1) احصل على مفتاح TMDB (مجاني)
1. سجّل في https://www.themoviedb.org
2. من إعدادات الحساب → API → اطلب "API Key (v3 auth)"
3. افتح ملف `js/config.js` وضع المفتاح مكان النص `ضع_مفتاح_TMDB_هنا`

### 2) افتح الموقع
- افتح `index.html` مباشرة في المتصفح، أو
- الأفضل: شغّل خادمًا محليًا بسيطًا حتى تعمل الطلبات بدون مشاكل CORS:
  ```
  cd الفولدر
  python3 -m http.server 8000
  ```
  ثم افتح `http://localhost:8000` في المتصفح.

### 3) انشره أونلاين (اختياري)
الموقع ملفات ثابتة بالكامل، لذلك يمكنك رفعه مباشرة على:
- GitHub Pages
- Netlify / Vercel (اسحب وأفلت الفولدر)
- أي استضافة عادية

## هيكل الملفات
```
index.html          الصفحة الرئيسية
css/style.css        كل التصميم (الألوان، الخطوط، البطاقات، المودال)
js/config.js         مكان وضع مفتاح TMDB
js/api.js            دوال الاتصال بـ TMDB و AniList
js/app.js            منطق العرض: الهيرو، الصفوف، البحث، المودال
```

## تخصيص سريع
- **تبديل اللغة**: فوق يمين الهيدر زر EN/عربي يبدّل واجهة الموقع بالكامل ولغة بيانات TMDB
  (المكتبة العربية أقل اكتمالًا من TMDB نفسها، فبعض العناوين/الأوصاف ترجع تلقائيًا للإنكليزي
  لو ما فيها ترجمة عربية بقاعدة بياناتهم). كل نصوص الواجهة نفسها موجودة بقاموس `STRINGS`
  بأعلى ملف `js/app.js` — تقدر تضيف لغة ثالثة بنفس الطريقة.
- **الألوان**: كل الألوان معرّفة كمتغيرات CSS في أعلى `css/style.css` تحت `:root`.
- **الخطوط**: `Aref Ruqaa` للعناوين، `Tajawal` للنصوص — يمكن تغييرهما من رابط Google Fonts
  في `index.html` ومن متغيرات `--font-display` و `--font-body`.
- **الأقسام**: لإضافة صف جديد (مثلاً "أفلام رعب")، أضف `<section class="row">` جديد في
  `index.html` بمعرّف `track-*` جديد، ثم نادِ `renderRow()` عليه من `js/app.js` بعد جلب
  البيانات المناسبة من TMDB (مثلاً `discover/movie` بفلتر نوع الرعب).
- **البطاقة على شكل تذكرة**: التأثير في class `.card` باستخدام `mask-image` — إن أردت
  بطاقات عادية بدون الشق الدائري، احذف خصائص `mask-image` و `-webkit-mask-image`.

## ملاحظات تقنية
- الموقع متجاوب بالكامل (جوال/تابلت/سطح مكتب).
- يدعم التنقل بلوحة المفاتيح ويحترم إعداد "تقليل الحركة" في نظام التشغيل.
- لا توجد أي مكتبات خارجية سوى خطوط Google Fonts — لا حاجة لـ npm أو أي أداة بناء.
